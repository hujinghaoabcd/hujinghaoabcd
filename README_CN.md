## 👋 关于我

我是一名 **地理信息科学（GIS）** 方向的博士研究生，研究兴趣涵盖 **GeoAI、空间统计、时空建模、交通预测、环境模拟与地理空间软件工程**。

我的工作重点是把地理学理论、数据驱动模型与可复现软件连接起来。我也持续将科研代码整理为可复用的开源工具，覆盖空间统计模型、时空神经网络、WebGIS 平台和科学计算工作流等方向。

- 🧠 研究：**GeoAI · 空间统计 · 时空建模 · 交通预测**
- 🌍 地学：**环境模拟 · 空气污染 · 地理空间大数据**
- 🧰 工程：**Scientific Python · 科研软件 · WebGIS · GIS 平台**
- ❤️ 开源：持续开发可复用的软件包、文档、教程与项目模板
